Design handoff · Phase 7b

SpeakUp — Free Talking (Nói chuyện với Minny)

Open, time-boxed spoken conversation between a Vietnamese child (~6–12) and the koala mascot Minny. Session ends at 5:00 or 12 turns, whichever comes first. Five states below, each rendered at phone (390), tablet (820) and desktop (1280). All copy final. Reuses minny-hero, minny-avatar, minny-bubble, minny-btn, fx-card, fx-btn from Phase 7a. See README.md for tokens, class names and reduced-motion notes.

1. Conversation 2. Minny đang nghĩ 3. Tap-to-play 4. Wrap-up 5. Summary
01 · Main state

Conversation — child ↔ Minny loop

Where most session time is spent. Minny hero + bubble at top, scrolling turn transcript, countdown timer (mm:ss, gold; amber final 30s), 12-dot turns-left rail, and the reused red 96×96 record button in idle state.

03 · iPad autoplay fallback

"🔊 Nghe Minny" — explicit playback trigger

Safari on iPad can block autoplay after an async fetch. When it does, the reply text is still visible and a warm gold chip lives inside Minny's bubble — not an error banner. Chip disappears once tapped (playback proceeds) and does not reappear that session.

Notes. Chip is a solid gold pill with navy label, glowing halo — reads as a friendly "tap me" affordance, not an error. Lives inside the bubble so it moves with the reply visually. On tap: chip fades out (200ms), audio plays, playback continues normally. If any subsequent reply is also blocked in the same session, chip reappears. Volume-up icon is inline SVG (same stroke-icon vocabulary as contact-row icons in the DS). Under reduced motion: glow pulse disabled; chip remains fully visible without animation.
04 · Cap reached

Warm wrap-up — cap hit (5:00 or 12 turns)

Session ends with intention: Minny in celebrate mood, a scripted goodbye line, timer settled at 0:00, dots filled all the way. Record button is replaced by a single forward CTA into the summary screen — never a dead stop. Same layout also covers the daily kill-switch case with alternate copy ("Hẹn gặp lại ngày mai nhé!").
