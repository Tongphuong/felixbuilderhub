# Environment bindings — felixbuilderhub.com
During `freeze-v1`, ordinary account GET/HEAD pages return a self-contained
Vietnamese HTML pause page with HTTP503, `no-store`, and `Retry-After: 60`.
The page exposes only the fixed `data-read2lead-state="account_temporarily_paused"`
marker; no request, account, or credential values are reflected. APIs and
non-GET/HEAD requests retain the JSON error. Both forms keep the same storage
fence and do not dispatch to the account host. HEAD pages have no response body.

Unified account host: story voice for ordinary students and the existing founder
test account receives restricted SQL-backed speech metadata. `READ2LEAD_CODES`
is retained only for validated legacy TTS cache reads; new cache writes and atomic
picture-retelling Azure reservations use account SQL. The reservation reads the
preserved current-month meter, refuses exhausted/unavailable/corrupt counters,
and retains usage after failed provider calls. No new binding or allowance is
introduced. Non-unified hosts retain their existing configuration.

Reference for all `env.X` references inside Cloudflare Pages Functions.
Bindings are configured in Cloudflare Pages dashboard → Settings →
Environment variables and bindings. This doc is the source of truth;
when adding a new binding, update this file FIRST, then add to Cloudflare,
then reference in code.

## Setup checklist (Cloudflare Pages dashboard)
When deploying to a fresh Cloudflare Pages project (e.g., preview branch
or new account):
1. KV → create namespace, bind as `READ2LEAD_CODES` (same name for both
   Production and Preview environments). For V2 state, also bind
   `READ2LEAD_PROGRESS`; until configured, code falls back to
   `READ2LEAD_CODES`.
2. Environment variables → add (Encrypt for all secrets):
   - `READ2LEAD_BACKEND_URL`
   - `READ2LEAD_BACKEND_SECRET`
   - Optional preview-only book pilot: READ2LEAD_BOOK_LEVELS=L1
   - `ADMIN_PASSWORD`
   - `TELEGRAM_BOT_TOKEN`
   - `TELEGRAM_CHAT_ID`
3. **R2 → bind the media bucket as `R2L_MEDIA` (bucket
   `felixbuilderhub-read2lead`) for BOTH the Production and Preview
   environments — they are configured separately.** Anything that stores
   binary media needs it: SpeakUp homework photos, the teacher's vision
   autofill, parent portfolio videos, Read2Lead gift photos. A missing
   binding does not fail at build time — it surfaces at runtime as
   `config_error` / "Hệ thống ảnh chưa được cấu hình." **Bindings only take
   effect on a NEW deployment: redeploy after adding one.**
4. On the Render side, ensure `READ2LEAD_BACKEND_SECRET` matches exactly.
5. Verify by hitting `/api/check-generation-status?code=...&pack_id=...`
   — should return JSON, not 500. Verify R2 by hitting
   `/api/speakup-homework-photo?code=NOPE-NOPE-0000&id=hp_000000000000` —
   should return 404 `photo_not_found`, **not** 500 `config_error` (that
   guard runs before auth, so a 500 means the binding is missing).

Unset outside the bounded operator window. No setting is configured by this

The named `Read2LeadAccountOperator` entry point exposes only internal export
and apply RPC, through a same-account service binding. Its HTTP fetch returns404;
the default public Worker still targets the adult object. A Wrangler-authenticated

public migration endpoint, new access key, restore command or automatic startup
merge is added. Preserve private backups on disk with0600 permissions. Release

RPC result limit without relaxing freeze checks, checksums or export limits.

with POST and `Content-Type: application/json`. Forward the body through the
internal entry point without parsing it between services. The fixed target and
freeze checks run before reading; the same input shape, configured pins, backup
and rollout checks run after parsing. This is an internal RPC method, not an
HTTP importer; public fetch still returns404. Keep the source and backup pins
independently verified before sending either form of merge input.
