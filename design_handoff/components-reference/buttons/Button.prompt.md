Gold star-light call-to-action button; use for any primary or secondary action, or as an inline `ghost` text link with an arrow.

```jsx
<Button href="/coaching#book">Đặt lịch tư vấn miễn phí →</Button>
<Button variant="secondary">Xem tiến độ con</Button>
<Button variant="ghost">Xem chương trình coaching →</Button>
```

Variants: `primary` (default, gold fill, navy text), `secondary` (outlined, gold on hover), `ghost` (inline gold text link). Sizes: `sm` / `md` / `lg`. Props: `href` (renders `<a>`), `block` (full width), `disabled`.
