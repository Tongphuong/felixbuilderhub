Design handoff · SpeakUp V1 · Wave D · Set 1

Free Talking — Choice-chip conversation view L1–L2 Scaffolded Mode

Scope: L1–L2 only. Per SPEC_SPEAKUP_V1.md §V1-D3 (amended 2026-07-10, founder directive) the turn ladder is choice/scaffold (L1–L2) → guided open questions (L3) → free production (L4–L5). Every screen in this file is the L1–L2 scaffolded mode only. L3 (guided open questions, no chips) and L4–L5 (production tasks — storytelling / presentation / debate, phase V1.P) are each their own separate, future handoff — not designed here.

Extends the approved Phase 7b Free Talking screen (ft-topbar, ft-hero, minny-transcript, ft-recorder, spk-rec-btn — all shipped in src/pages/speak-up.astro today). This handoff does not redesign that chrome — it adds the option chips, sentence frame, sentence-starter hint, repair-ladder states and hands-free control called for in SPEC_SPEAKUP_V1.md §V1-D2/V1-D3. New class names are prefixed minny- to match the existing vocabulary. See README.md for the full component reference, copy list, and the "Level gating" section.

01 · Turn state · L1–L2 Scaffolded Mode

Minny's turn ends with option chips — hint visible (L1)

At L1–L2, every Minny turn that expects a small answer set ends with 2–3 tappable chips (word + emoji) plus a dashed sentence-starter hint above them. Tapping a chip never answers for the kid — it only reveals what to say next (Screen 2). Hands-free is ON here, so once Minny finishes speaking, VAD starts listening automatically (indicator shown near the recorder).

02 · After tap · L1–L2 Scaffolded Mode

Tap "🍕 pizza" → sentence frame revealed, mic auto-arms

Tapping a chip never submits an answer. It fills the sentence frame ("I like ___!" → "I like pizza!"), marks the tapped chip selected and dims the others, and arms the mic — the kid still has to say it out loud. With hands-free ON, VAD listening starts immediately (shown below); with hands-free OFF the kid sees "Nhấn để nói, con nhé!" prompting a manual tap (see Screen 3 for the OFF variant).

03 · L2 progress + manual mode · L1–L2 Scaffolded Mode

L2: sentence-starter hint is gone · hands-free OFF

Still entirely within the L1–L2 scaffolded mode — chips stay for the whole range. Contrast board for two independent things that both change with progress/settings, neither of which is a level transition to L3: (1) the starter hint fades out with in-range success (L1 → later L2) — chips alone are enough scaffolding by then; (2) hands-free is a kid/parent-controlled toggle, not tied to level — when off, the mic waits for an explicit tap and shows a static prompt instead of the pulsing listening indicator. (L3 itself drops chips entirely for guided open questions — out of scope for this handoff, see README "Level gating".)

04 · Repair ladder — step 1 · L1–L2 Scaffolded Mode

(a) Simpler rephrase

Scenario: Minny asked "Con có nuôi thú cưng không?" (open). The transcript came back low-content/garbled. Step 1 of the repair ladder rephrases into a smaller, simpler question — same chip UI, just an easier ask. Tagged quietly so a parent/teacher watching over the shoulder understands why the question changed; never shown as an error to the kid.

(b) Two big choice buttons

If the rephrase still doesn't resolve, step 2 asks the kid to confirm what Minny thinks it heard, using two large full-width buttons — bigger than the regular option chips, since this is now a direct disambiguation, not open scaffolding.

Notes. minny-repair-choice-btn is 56px min-height (well over the 44px floor) and full-width on phone / paired on desktop — deliberately bigger than minny-option-chip to read as "pick one, this is the last resort before Minny just tells you." This is the one place tapping alone can resolve the turn (per V1-D2), which is why it's visually distinct (large, centered, no chip styling) from the option chips used everywhere else.
06 · Repair ladder — step 3 (final) · L1–L2 Scaffolded Mode

(c) Model-and-repeat, then move on

Last ladder step (max 2 repair turns total, per acceptance criteria) — Minny just models the answer and invites one repeat, with a replay chip reusing the existing minny-play-chip from Phase 7b. Whether the kid repeats it or not, Minny moves on warmly — this step never blocks progress.
