Never a dead end

2/6 uses gold, not red. Primary CTA is always a forward action — "Thử lại 🎤", never "Fail".

Smile ≠ Rubric

The smile reminder is a dashed-gold chip, distinct from the rubric list — it can't be auto-verified, so it's never scored.

Responsive, not stretched

Phone stacks 1-col. Tablet splits into 2-col with breathing room, still touch-first. Desktop centers with max-width and adds a 3-column recording view — not a wide phone.

Motion, restrained

Only the red REC button pulses. Minny bobs 4px. All motion honors prefers-reduced-motion.
