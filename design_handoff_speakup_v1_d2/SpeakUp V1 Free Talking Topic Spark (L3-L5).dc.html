Design handoff · SpeakUp V1 · Wave D2

Free Talking — Topic Spark L3–L5 Production Mode

Scope: L3–L5 only. Per SPEC_SPEAKUP_V1.md §V1-D3 (rewritten 2026-07-10 evening) these levels are not guided — no choice chips, no sentence frames, no photos anywhere in these screens (photos stay in homework mode by founder decision). L3 gets a topic pick + on-demand hints. L4–L5 add three optional production games on top of the same topic-spark base. L1–L2's chip/frame system (Wave D, Set 1) is a completely different mode and does not appear here.

Extends the approved Phase 7b Free Talking screen (ft-topbar, ft-hero, minny-transcript, spk-rec-btn, the Wave D hands-free toggle + listening indicator) — reused verbatim, unmodified. Topic tiles reuse TopicTile.astro's rendered look (fx-topic family) and the exact 12 HUB_TOPICS from src/pages/ho-so/ho-so-topics.ts, laid out with the 3-column grid pattern from r2l/start.astro. See README.md for the full component reference, copy list, and open questions.

A1 · Session start · L3

Topic pick — the first thing an L3 kid sees, before turn 1

This screen replaces "jump straight into turn 1." Minny asks what to talk about, the kid taps one of the 12 HUB_TOPICS tiles (exact labels/emoji, unchanged) or "Minny chọn 🎲" to let Minny pick. The topic is stored on the session only (starter_topic) — never written to the profile. No timer/turn-dots yet since the session itself starts once a topic is confirmed; the only way out is the same end/back control as every other screen.

A2 · Session start · L4–L5

Same topic picker, plus three optional production games on top

L4–L5 kids see everything from A1 plus three game cards above the topic grid — visually distinct (larger, gold-tinted, one-line description) so they read as a different kind of choice, not more topic tiles. Picking a game still needs a topic underneath it for vocabulary seeding, so tapping a game card scrolls to/highlights the topic grid rather than replacing it — topics are never optional at this step, only which framing wraps the conversation.

B2 · In-conversation · L3–L5

Hint offered — kid stalled, button pulses gently

Same turn, a few silent seconds later: the app detected a stall (no speech, mic still armed) and offers help — the button gets a soft pulse and a small "Cần gợi ý không?" affordance appears beside it. This is a nudge, not a takeover: nothing blocks the screen, no modal, the kid can keep trying to speak and the offer just sits there until tapped or the kid answers on their own (in which case it quietly reverts to B1).
